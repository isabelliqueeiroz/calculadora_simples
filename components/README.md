🧮 Calculadora Simples — React JS

Projeto desenvolvido em React JS para realizar cálculos matemáticos básicos.

⚙️ Funcionalidades
Inserção de dois números;
Seleção da operação: +, -, * e /;
Exibição do resultado;
Botão para limpar os campos;
Validação de divisão por zero.
🛠️ Tecnologias
React JS
JavaScript
CSS
Vite
📚 Conceitos utilizados
Componentes React;
useState;
Eventos onChange e onClick;
switch;
Renderização condicional;
Estilização com CSS.
